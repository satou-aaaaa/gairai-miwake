# 外来生物みわけ（gairai-miwake）

身近な生き物の名前と手がかりを見て、法律での区分（在来種・外来種（指定なし）・特定外来生物・条件付特定外来生物）を当てる1日5問の学習ゲーム。正解したら「どこから来た？」（もとの産地）も選ぶ。

遊ぶ: <https://satou-aaaaa.github.io/gairai-miwake/>

- 区分は環境省「特定外来生物等一覧」（<https://www.env.go.jp/nature/intro/2outline/list.html>）、きまりは環境省「何が禁止されているのか」「条件付特定外来生物」「外来種被害予防三原則」、もとの産地と見た目の手がかりは国立環境研究所「侵入生物データベース」（<https://www.nies.go.jp/biodiversity/invasive/>）で確かめたことだけ（2026-11-17 に読んだ）。生き物の絵は出しません。
- 特定外来生物の一覧は、新しく指定されて変わることがあります。このゲームは法律の助言や、公式の情報の代わりではありません。正しい一覧は環境省「日本の外来種対策」（<https://www.env.go.jp/nature/intro/>）で確かめてください。
- 場面はすべて練習のために作ったものです。記録は遊ぶ人のブラウザだけに残り、外へ送りません。
